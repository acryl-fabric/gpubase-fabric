# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Use GitHub's private vulnerability reporting: **Security → Report a vulnerability** on this
repository. If that is unavailable, contact the maintainers at ACRYL Inc. via
https://www.acryl.ai/.

We aim to acknowledge reports within 5 business days.

## Scope

- Code in this repository (open-source Core).
- Vulnerabilities in third-party products (switch NOS, NIC/DPU firmware, Kubernetes) found during
  research should be reported to the vendor first. Exploit details are published here only after
  coordinated disclosure.

## 보안 취약점 제보 (한국어)

공개 이슈 대신 저장소의 **Security → Report a vulnerability**(비공개 제보)를 사용해 주세요.
연구 중 발견한 타사 제품 취약점은 해당 벤더에 먼저 제보하고, 공개는 조율된 공개(coordinated disclosure) 이후에 합니다.
