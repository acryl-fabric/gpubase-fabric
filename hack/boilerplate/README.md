# License header boilerplate

All new source files must start with the MPL-2.0 header (Exhibit A of the MPL).
Use the comment syntax of the language. Replace the copyright holder with your
organization if you are not ACRYL Inc.

```text
Copyright 2026 ACRYL Inc. and the JONATHAN GPUBASE Fabric contributors
SPDX-License-Identifier: MPL-2.0

This Source Code Form is subject to the terms of the Mozilla Public
License, v. 2.0. If a copy of the MPL was not distributed with this
file, You can obtain one at https://mozilla.org/MPL/2.0/.
```

Files: `boilerplate.go.txt` (`//` style), `boilerplate.sh.txt` (`#` style).
`hack/check-mpl-header.sh` accepts either the SPDX line or the Exhibit A text.
