# libs

여러 컴포넌트가 함께 쓰는 **언어별 공용 라이브러리**를 둡니다.

| 경로 | 언어 | 예시 |
|---|---|---|
| [`go/`](go/README.md) | Go (루트 `go.mod` 모듈에 포함) | gNMI/gNOI 클라이언트, 공통 로깅·메트릭 헬퍼 |
| [`python/`](python/README.md) | Python | 텔레메트리 파서, 실험 공용 유틸리티 |

필요한 언어 디렉터리는 처음 쓸 때 만듭니다(예: `libs/cpp/`, `libs/ts/`).

## 규칙

- **컴포넌트끼리 직접 import하지 않습니다.** 공용 코드는 `libs/<언어>/<이름>/`으로 옮기고, 컴포넌트 간 연동 계약은 [`api/`](../api/README.md)에 둡니다.
- 언어를 넘는 공유(예: Go 엔진 ↔ Python 분석 모듈)는 `api/`의 proto(gRPC)로만 합니다.
- `libs/<언어>/<이름>/`은 각각 하나의 컴포넌트로 취급합니다. README, Makefile(`build`, `test`), `tests/`가 필요합니다. "개발 연차"와 "계획서상 산출물명"은 "해당 없음"으로 적어도 됩니다.
- `libs/`가 바뀌면 CI는 전체 컴포넌트를 다시 빌드·테스트합니다.
- 담당: 기본은 `fabric-acryl`입니다. 라이브러리를 추가한 기관을 CODEOWNERS에 함께 등록합니다.
