# libs/go

Go 공용 라이브러리. 루트 모듈 `github.com/acryl-fabric/gpubase-fabric`에 속하므로
`import "github.com/acryl-fabric/gpubase-fabric/libs/go/<name>"`으로 씁니다.
의존성이 무거운 라이브러리는 자체 `go.mod`를 둘 수 있습니다([COMPONENT_CONTRACT.md](../../docs/governance/COMPONENT_CONTRACT.md) §4).

아직 라이브러리가 없습니다. 첫 라이브러리는 `hack/new-component.sh --path libs/go/<name> ...`로 만듭니다.
