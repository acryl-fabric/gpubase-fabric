# research

논문 재현 코드와 실험 코드를 두는 곳입니다. 컴포넌트 계약을 완화해 적용합니다.

## 규칙

- 하위 폴더 하나가 실험 하나(또는 논문 하나)입니다. 이름은 `{기관}-{주제}` (예: `ajou-pcie-contention-study`)
- **필수**: `README.md`(논문·실험 정보, 담당 기관, 재현 방법, 사용 데이터의 출처와 라이선스), 소스 파일의 MPL-2.0 헤더
- 선택: Makefile, 테스트. CI 빌드 대상이 아닙니다.
- 데이터셋, 체크포인트, 패킷 캡처 같은 대용량 파일은 커밋하지 않고 외부 위치를 링크합니다.
- 실험 결과에 내부 IP, 호스트명, 장비 시리얼 등 환경 정보가 남지 않게 정리합니다.
- 제품화할 코드는 해당 계층의 컴포넌트로 옮깁니다.

## README 템플릿

```markdown
# <실험 이름>
- 담당 기관 / 연구자:
- 관련 논문 (venue, year, link):
- 재현 환경 (HW/SW):
- 재현 방법:
- 데이터 출처·라이선스:
```
